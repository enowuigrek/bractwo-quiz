# Bractwo Quiz

Autorska aplikacja quizowa [Bractwa Piwnego](https://bractwopiwne.pl) – Towarzystwa Promocji Kultury Piwa. Na telewizorze w piwiarni wyświetla się quiz z kodem QR, uczestnicy dołączają z telefonów, odpowiadają na czas i walczą w rankingu, a prowadzący steruje wszystkim z telefonu.

Status: w budowie (MVP).

## Stack

Next.js · Supabase (Postgres, Realtime, Storage) · Vercel
